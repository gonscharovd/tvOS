# Паспорт проекта testOS

**Название:** testOS  
**Репозиторий:** [gonscharovd/tvOS](https://github.com/gonscharovd/tvOS)  
**Основа:** форк [techgenius1/tvOS-Launcher](https://github.com/techgenius1/tvOS-Launcher)  
**Лицензия репозитория:** Apache-2.0  
**Дата среза:** 2026-11-09

## Назначение

Развивать собственный лёгкий и удобный launcher для Android TV с русскоязычным интерфейсом и управлением с телевизионного пульта. Главная целевая среда пользователя — телевизор Sber SDX-50U4123B на Android 9 / API 28 / ARMv7. Кодовая база сохраняет более широкую совместимость с Android TV API 24+.

Это приложение-оболочка Android TV, а не новая прошивка и не замена системного образа телевизора.

## Цели

- Сделать Night Scenes единственным домашним интерфейсом.
- Сохранить быструю и предсказуемую навигацию с D-pad.
- Предоставить удобный запуск приложений, поиск, папки/скрытые приложения и управление недавними приложениями.
- Дать пользователю полезные системные инструменты: Control Panel, Button Mapper, VPN shortcut/integration, Weather, CleanYourTV, ADB permission repair.
- Поддерживать безопасное OTA-обновление из GitHub Releases.
- Сохранять настройки и данные при упрощении архитектуры.
- Не требовать root и не модифицировать системные разделы телевизора.

## Целевая аудитория и устройство

- Основной пользовательский сценарий — персональный launcher на Sber SDX-50U4123B.
- Кодовая база рассчитана на Android TV / Google TV с минимальным API 24.
- Подтверждённые характеристики целевого телевизора из пользовательских материалов: Android 9 / API 28, ARMv7, SoC MediaTek MT9632, плата CV9632-KH, firmware 1.103.91-b32273.
- Совместимость с другими Android TV устройствами заявлена в документации репозитория, но должна проверяться на каждом классе устройств.

## Основные пользовательские сценарии

1. Выбор testOS как HOME launcher и возврат на домашний экран кнопкой Home.
2. Перемещение по Night Scenes, доку, More Apps и настройкам пультом.
3. Запуск, переупорядочивание, скрытие приложений и настройка пользовательских элементов.
4. Использование поиска по приложениям/настройкам и поиск названий через JustWatch.
5. Открытие Control Panel и Recent Apps поверх домашнего экрана или другого приложения.
6. Управление погодой, VPN, кнопками пульта, DND, режимами питания и другими поддерживаемыми функциями.
7. Безопасное отключение/восстановление пакетов через CleanYourTV с проверкой реального состояния.
8. Проверка OTA-обновления, загрузка APK и установка штатным Android PackageInstaller.
9. Экспорт/импорт разрешённого набора настроек.

## Ключевые возможности в текущей кодовой базе

- Night Scenes: фоновые сцены, часы, погода, док и библиотека приложений.
- Search: локальные приложения/настройки и поиск контента.
- ControlPanelOverlay и RecentAppsOverlay.
- ButtonMapper и PowerService (AccessibilityService).
- CleanYourTv и LocalAdb.
- Weather, VpnController, AirPlayGuard, Inputs, SleepReceiver.
- AppUpdater и VersionComparator.
- CustomMedia: пользовательские иконки/обои и JSON backup/restore.
- Дополнительный модуль Presentation в `src/.../present/`; его текущая пользовательская роль требует отдельной проверки перед удалением.

Точный список и актуальный статус смотри в [02_ARCHITECTURE.md](02_ARCHITECTURE.md) и [03_CURRENT_STATE.md](03_CURRENT_STATE.md).

## Границы проекта

В область проекта входят приложение, его локальные настройки, сборка APK, тесты, GitHub Actions, OTA-релизы и совместимость с Android TV.

Вне области без отдельного продуктового решения:
- перепрошивка ТВ, изменение bootloader, /system, /vendor или eMMC;
- root и обход системных ограничений;
- удаление или отключение критических компонентов Sber/Android;
- публикация OTA без согласования;
- массовое добавление функций, не согласованных Product Owner;
- перенос пользовательских данных на сервер или добавление аналитики/учётных записей.

## Критерии успеха

- APK стабильно собирается в CI и локально одинаковыми параметрами.
- Версия, package ID и сертификат подписи согласованы между сборкой, релизом и установленным приложением.
- Launcher запускается на целевом Sber TV, корректно обрабатывает D-pad, Home/Back, сон/пробуждение и возврат из приложений.
- OTA обновляет установленный APK без удаления приложения и потери данных.
- Настройки и миграции не уничтожают существующие пользовательские значения.
- CleanYourTV защищает критические пакеты и сохраняет только подтверждённое состояние.
- Документация совпадает с кодом и состоянием GitHub.
